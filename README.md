# Sweezkh

A static personal CS2 portfolio for Sweezkh, built for GitHub Pages with no framework or build step.

## Pages

- Home — player introduction, story, featured archive, location, and social profiles
- Gallery — responsive image collection with an accessible lightbox
- Roster — keyboard-friendly player selector
- Highlights — match clips loaded on demand
- Music — lazy-loaded SoundCloud selection
- Edits — montage archive loaded on demand

## Structure

- `assets/css/styles.css` — shared responsive design system
- `assets/js/main.js` — navigation, reveal effects, lightbox, roster, and media loading
- `images/`, `videos/`, `edits/` — existing media archive

Open `index.html` directly or serve the folder with any static HTTP server. The `CNAME` file preserves the custom domain configuration for `sweezkh.pp.ua`.
